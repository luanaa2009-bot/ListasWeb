O que é JavaScript?

JavaScript é uma linguagem de programação criada para tornar as páginas da internet mais dinâmicas e interativas. Sua criação teve como principal motivação permitir que os sites respondessem às ações dos usuários, como cliques, preenchimento de formulários e animações.

O JavaScript pode ser executado no navegador, onde interage diretamente com os elementos da página HTML, ou no servidor, por meio de ambientes como o Node.js, permitindo processar informações e acessar bancos de dados.

No navegador, o JavaScript funciona em um ambiente chamado sandbox, que é uma área isolada e segura que limita o acesso do código aos recursos do computador do usuário, protegendo seus dados e sua privacidade.

A linguagem possui objetos globais que oferecem funcionalidades importantes. O objeto document permite acessar e modificar elementos HTML da página. O objeto console permite exibir mensagens e informações no console do navegador. Já o objeto alert permite mostrar caixas de diálogo com mensagens para o usuário.
