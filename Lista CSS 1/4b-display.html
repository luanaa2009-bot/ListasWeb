Explicação

static é o padrão: o elemento segue o fluxo normal e ignora top, left, etc.

relative: o elemento continua reservando seu espaço original no fluxo, mas é deslocado visualmente a partir dessa posição (20px para baixo e 40px para a direita). Por isso o quadro roxo ("normal") fica onde ficaria se o vermelho não tivesse sido movido.

absolute: sai do fluxo (não ocupa espaço) e é posicionado em relação ao ancestral posicionado mais próximo. Como o pai tem position: relative, o quadro verde vai para o canto inferior direito do pai. Sem isso, ele usaria a página como referência.

Referência: MDN Web Docs. position. 2025. https://developer.mozilla.org/pt-BR/docs/Web/CSS/position
