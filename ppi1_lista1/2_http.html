Protocolo HTTP

HTTP (HyperText Transfer Protocol) é o protocolo que define como o navegador (cliente) pede recursos a um servidor e como o servidor responde. Funciona no modelo requisição e resposta: o cliente envia uma request e o servidor devolve uma response. HTTPS é o HTTP com criptografia (TLS).

Como funciona

  1. O usuário digita uma URL no navegador.
  2. O navegador descobre o IP do servidor (DNS) e abre uma conexão.
  3. Envia uma requisição HTTP (ex.: GET /index.html).
  4. O servidor responde com um código de status e o conteúdo.
  5. O navegador renderiza a página.

Métodos principais

MétodoUso
GETBuscar um recurso
POSTEnviar dados (ex.: formulário)
PUTAtualizar um recurso
DELETERemover um recurso

Accept-Encoding: gzip, deflate, br
Connection: keep-alive

Campos do request

GET / HTTP/1.1
Método, caminho e versão do protocolo.
Host
Domínio do servidor de destino.
User-Agent
Identifica o navegador e o sistema operacional.
Accept
Tipos de conteúdo que o cliente aceita.
Accept-Language
Idiomas preferidos.
Accept-Encoding
Compressões aceitas.
Connection
Se a conexão continua aberta após a resposta.

Resposta capturada

HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
Content-Length: 12345
Server: nginx
Date: Tue, 29 Sep 2026 12:00:00 GMT
Cache-Control: max-age=3600

Campos do response

200 OK
Código de status: sucesso.
Content-Type
Tipo e codificação do conteúdo enviado.
Content-Length
Tamanho do corpo em bytes.
Server
Software do servidor.
Date
Data e hora da resposta.
Cache-Control
Regras de cache no navegador.

Códigos de status

  • 2xx: sucesso (200 OK)
  • 3xx: redirecionamento (301, 302)
  • 4xx: erro do cliente (404 Not Found)
  • 5xx: erro do servidor (500)
